# Перевірка комплекту — 2026-10-09

## Виконано

- npm install: успішно; точні версії зафіксовані в package-lock.json.
- npm run check: TypeScript без помилок; doctor підтвердив залежності та однакову версію Remotion 4.0.534.
- Remotion CLI compositions: усі 5 стартових композицій доступні, 1080×1920, 30 fps, 900 кадрів.
- npm run setup:skills: успішно встановлені офіційні Remotion Skills, Snapcn skills і video-shotcraft у локальному тестовому проєкті. У ZIP вони не включені; встанови повторно на новому комп'ютері.
- Відрендерені й візуально переглянуті кадри GSAP, Three.js, SVG/Lottie та титрів.
- Повністю відрендерено Hybrid: 900 кадрів, 540×960, H.264 + AAC, 30 fps, 30.016 секунди з контейнерною аудіотривалістю.
- Прев'ю і контактний аркуш включені в examples/.
- 3D перевірено через software GL (swangle). Для середовища без GPU є параметр --software.
- Синтаксис Node-скриптів перевірено. Виправлено конфлікт початкової версії Zod, ім'я Remotion Folder і метадані тестової Lottie-анімації.
- Аудіопотік присутній, піковий рівень прев'ю -22.1 dBFS, кліпінгу за цією перевіркою немає. Тестовий фон навмисно тихий; це не фінальний саунд-дизайн і не перевірка loudness за LUFS.

## Що не перевірено

- Запуск на Windows та hardware GL: виконано у Linux; Windows-команди підготовлені, але не запускалися тут.
- Повний рендер 1080×1920: команди готові, базова перевірка виконана на 540×960.
- Skia, Rive та Remotion Bits: додаткові установки й окремі промпти; ці експерименти не виконувалися.
- Snapcn-компоненти: скіли встановлені, самі компоненти додаються агентом на етапі 5.
- video-shotcraft creative workflow: установка перевірена; авторську режисуру виконує агент за етапом 7.
- remotion-qa: надано джерело та порядок підключення; інструмент не запускався.
- Сайт DevGuide не вдалося прочитати через дослідницький доступ. Початковий brief не містить цін, статистики або неперевірених поточних пропозицій.
