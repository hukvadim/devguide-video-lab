# ТЗ: лендінг «AI як робочий помічник» (Вадим Гук)

## Мета
Перевести трафік з Meta в Telegram-розмову. Головна дія: клік «Написати в Telegram» (мікроконверсія), справжня заявка — повідомлення.
Два варіанти hero за UTM: `?a=abroad` (аудиторія А) і `?a=business` (аудиторія Б). Решта сторінки спільна.

## Стек
- Next.js (App Router) + React + TypeScript, статичний експорт / Vercel.
- Tailwind CSS + shadcn/ui (Accordion для FAQ, Button, Card, Badge).
- GSAP + ScrollTrigger + SplitText (заголовки), Lenis (smooth scroll, синхрон з ScrollTrigger).
- Three.js + React Three Fiber + Drei: один легкий 3D-об'єкт у hero (скляна «бульбашка чату», що перетікає в «вікно сайту»). Lazy-load після LCP, на мобайлі зі слабким GPU і при `prefers-reduced-motion` — статичний AVIF.
- Відео hero: 8 с з Google Flow (`03-video/*` промпти), WebM (VP9) + MP4 (H.264) fallback, ≤2 МБ, `muted playsinline loop`, постер AVIF/WebP.
- Зображення: AVIF/WebP через `next/image`.

## Структура (AIDA)
1. **Attention — Hero.** Заголовок А: «AI у тебе вже є. Навчимо його працювати.» / Б: «Задачі бізнесу з AI — без чекання підрядника». Підзаголовок: «10 індивідуальних годин з розробником. Один проєкт від ідеї до запуску.» CTA: «Безкоштовні 30 хв у Telegram». Фон: Flow-відео або 3D.
2. **Interest — Проблема.** 3 картки: «AI відповідає загально», «Не знаєш, з чого почати проєкт», «Залежиш від підрядника/знайомого айтішника».
3. **Interest — Що робимо (5 кроків)** з таймлайном на ScrollTrigger: діалог → ТЗ; AI-інструменти й доступи; сайт і публікація; аналітика й UTM; креатив і перша кампанія під наглядом. Примітка дрібно: бот/автоматизація — окремий фокус або наступний етап.
4. **Desire — Як проходить.** 10 × 1 год, 2 рази на тиждень, ~5 тижнів, онлайн українською, самостійна практика між заняттями, обсяг під стартовий рівень. Процес у 6 кроків (з /about): знайомство → план → практика на проєкті → запис уроку → портфоліо → підтримка.
5. **Desire — Про Вадима.** Фото, «10+ років веброзробки, викладає з 2022, 300+ учнів, 5.0 на Superprof (48 відгуків)». Портфоліо (скриншоти): DevGuide, babayaga.lviv.ua, solar-energy-30-blackout, LOVIM. Підписати: «проєкти Вадима».
6. **Desire — Відгуки.** 3 дослівні цитати з Superprof з посиланням на профіль (лише після перевірки тексту й згоди).
7. **Action — Ціна.** $300 за 10 годин ($30/год). Що входить / що не входить (Claude Pro ~$20/міс окремо; результат залежить від практики; без гарантії працевлаштування).
8. **FAQ** (Accordion): «Я зовсім не айтішник», «Скільки часу на практику», «Що якщо пропущу заняття», «Яка оплата» (уточнити у Вадима), «Чи можна для співробітника», «Чи буде бот».
9. **Action — фінальний CTA** + sticky кнопка на мобайлі «Написати в Telegram».

## Аналітика
- Meta Pixel: `PageView`, `ViewContent` (скрол до «Ціна»), `Contact` (клік Telegram). Conversions API — план через Vercel function, після запуску.
- GA4: ті самі події, `generate_lead` на клік Telegram.
- UTM схема: `utm_source=meta&utm_medium=paid&utm_campaign={A_abroad|B_business|C_banner}&utm_content={video_a|video_b|banner}`. Передавати в Telegram-посилання як `?start=<campaign>` (якщо буде бот) або хоча б логувати.
- Cookie-банер з «Тільки необхідні», Pixel вантажити після згоди (ЄС/Польща — GDPR).
