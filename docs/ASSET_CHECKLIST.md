# Матеріали

Для запуску стартових сцен нічого додавати не потрібно.
Для справжнього фінального відео бажано додати:

1. `public/assets/devguide-home.png` — скриншот головної сторінки.
2. `public/assets/devguide-learning.png` — актуальна програма навчання.
3. `public/assets/vadim.png` — фото викладача, бажано з прозорим фоном.
4. `public/assets/logo.svg` — справжній логотип, якщо він є.
5. `public/assets/voiceover.wav` — українська озвучка.
6. `public/assets/music.wav` — музика з дозволом на використання.
7. `public/assets/mascot.riv` — для окремого Rive-тесту.

Якщо матеріалів немає, агент створює графіку кодом і підписує будь-які демо-інтерфейси як концепти. Він не вигадує зовнішність Вадима, відгуки або статистику.
У стартових сценах є простий оригінальний синтезований музичний фон `lab-bed.wav`. Це тестовий фон, не професійний саундтрек.
`src/orbit.json` — власна мінімальна Lottie-анімація для перевірки інтеграції.

## Початковий текст для озвучки

Хочеш навчитися веброзробки? Почни з практики. Пиши код, розбирайся, як він працює, і створюй власний проєкт. DevGuide — навчання HTML, CSS, JavaScript і React разом із ментором. Від першої ідеї — до результату, який можна показати. Почни свій шлях із DevGuide. devguide.com.ua.

Адаптуй текст після перевірки сайту. Підганяй тривалість ролика під реальне аудіо, а не навпаки. Для версії без голосу залиш читабельні титри.
