# Матриця тестування

| Варіант | Стартова композиція | Технологія | Що оцінювати |
|---|---|---|---|
| Motion | DevGuide-Motion | GSAP, frame springs | Вхід тексту, ритм, плавність |
| 3D | DevGuide-Three | Three.js, R3F | Світло, матеріал, камера, headless render |
| Vector | DevGuide-Vector | SVG paths, Lottie | Промальовування, зв'язність сцен |
| Captions | DevGuide-Captions | Caption types, editorial timing | Читабельність, тривалість |
| Hybrid | DevGuide-Hybrid | TransitionSeries | Переходи; це демонстраційна збірка |
| Components | Додає агент | Snapcn, Remotion Bits | Виграш часу, узгоджений стиль |
| Skia / Rive | Додає агент окремо | WASM / .riv | Сумісність, графіка, потреба в матеріалах |
| Hero / Final | Додає агент | video-shotcraft + вибрані прийоми | Сценарій, ясність, монтаж, звук |

Для чесного A/B використай однакові меседжі, тривалість, FPS, розмір, CRF та комп'ютер.
Зафіксуй: час реалізації, preview render, final render, максимальне споживання пам'яті якщо вимірюється, розмір MP4.
Оцінки 0–10: перші 3 секунди, ясність меседжу, типографіка, ритм, звук, end card, загальне враження.
Скіли не є бібліотеками. Успішне встановлення скіла не дорівнює його фактичному використанню.

## Acceptance criteria

- Немає відсутніх шрифтів/медіа, помилок у render logs, чорних несподіваних кадрів.
- Текст читабельний у 540×960 та не обрізаний у 1080×1920.
- UI Reels/Shorts не закриває ключовий текст; робочі відступи — орієнтир, перевір фактичний інтерфейс платформи.
- Однаковий кадр у Studio і still render; анімації не залежать від wall clock.
- CTA має час для прочитання. Звук без грубих стиків/кліпінгу.
- Вказано, які матеріали реальні, а які є графічними концептами.
