# Промпт: neo-brutalism лендинг

Слово: **БРУТ** · матеріал: https://devguide.com.ua/materials/insta-brutalism

Брутал-стиль запам'ятовується саме тому, що виглядає «грубо»: товсті рамки, жорсткі тіні без розмиття, сирий шрифт, кислотні кольори. Пасує креативним агенціям, мерчу, подіям.

```
Зроби лендинг у стилі neo-brutalism для [бренду / події].
Товсті чорні рамки (3–4 px), жорсткі тіні зі зсувом без розмиття, 2–3 яскраві кольори, великий гротеск.
Кнопки — прямокутні, при наведенні тінь зникає (ефект «натискання»).
Секції: перший екран, 3 переваги, відгук, заклик до дії. Мобільна версія обов'язкова.
```
