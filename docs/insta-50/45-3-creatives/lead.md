# Чекліст: 3 креативи на один оффер

Слово: **КРЕО** · матеріал: https://devguide.com.ua/materials/insta-3-creatives

Не роби одну рекламу — зроби три з різних кутів і залиш ту, що дає дешевші заявки.

1. **Біль** — що болить у клієнта зараз.
2. **Результат** — як буде після.
3. **Довіра** — відгук, кейс або ти в кадрі.

**Чекліст кожного креативу:**
- перші 2 секунди — хук, зрозумілий без звуку;
- один оффер і одна дія;
- субтитри;
- формат 9:16 і 4:5;
- без обіцянок, яких не можеш довести.

```
Мій оффер: [що продаю, кому, ціна]. Напиши 3 сценарії рекламного ролика по 15–20 с: кут «біль», кут «результат», кут «довіра». Для кожного: хук, 3 кадри, текст на екрані, заклик.
```
