# Шпаргалка: радіуси і настрій

Слово: **РАДІУС** · матеріал: https://devguide.com.ua/materials/insta-radius

Радіус кутів змінює характер сайту:

- **0–4 px** — строго: юристи, фінанси, B2B.
- **8–12 px** — дружньо: більшість сервісів і магазинів.
- **16–24 px** — м'яко: застосунки, дитячі й lifestyle-бренди.
- **999 px (пігулка)** — грайливо: кнопки, теги.

**Правило:** один радіус для системи (і, можливо, пігулки для тегів). Різні радіуси на одній сторінці виглядають випадково.

```
Зроби на всьому сайті один радіус кутів 12 px для карток, полів і кнопок; теги — пігулки. Перевір, щоб ніде не лишилось інших значень.
```
