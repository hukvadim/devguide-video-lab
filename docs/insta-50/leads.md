# Матеріали для бота (insta-50)

Кожен розділ `## NN · СЛОВО · Назва` — окремий матеріал DevGuide (стаття, безкоштовно). Бот за словом надсилає посилання на нього.
Розкладання по папках і завантаження чернетками: `node scripts/insta-leads.mjs`. Промпти — як є, без вигаданих цифр.

## 03 · ПРОЄКТ · Інструкція для проєкту в ChatGPT і Claude

Проєкт — це папка в ChatGPT або Claude, де лежить одна інструкція про тебе і файли. Кожен новий чат у проєкті вже знає контекст, і не треба щоразу пояснювати все з нуля.

**Що покласти у файли:** прайс або перелік послуг, 2–3 приклади робіт, правила (тон, мова, що ніколи не обіцяти), часті питання клієнтів.

**Шаблон інструкції** (заповни дужки і встав у налаштування проєкту):

```
Ти — мій помічник у [сфера: сайти для малого бізнесу].
Про мене: [хто я, досвід, місто].
Мої клієнти: [хто вони, що їм важливо].
Як відповідати: українською, коротко, по пунктах, без води.
Завжди: спершу спитай, чого бракує, якщо задача неясна.
Ніколи: не вигадуй ціни, терміни й факти — бери їх з файлів проєкту або питай мене.
Файли проєкту: прайс, приклади робіт, правила — використовуй їх як джерело правди.
```

**З чого почати:** три проєкти — «Клієнти» (листування, ТЗ, оцінки), «Контент» (пости, сценарії), «Навчання» (те, що зараз вивчаєш).

## 05 · ЗВІТ · Промпт: звіт про конкурентів

Режим глибокого пошуку (Deep Research у ChatGPT або Research у Claude) сам ходить по сайтах і збирає звіт. Твоє завдання — дати чітке питання і перевірити джерела.

```
Знайди 5–7 конкурентів [мого бізнесу: кав'ярня в центрі Києва].
Для кожного: назва, сайт, що продають, ціни (якщо є на сайті), сильні сторони, слабкі місця сайту (швидкість, мобільна версія, заклик до дії).
Зведи в таблицю, під таблицею — 5 ідей, як мій сайт може бути кращим.
Біля кожного факту — посилання на джерело. Якщо даних немає — пиши «немає даних», не вигадуй.
```

**Перевір:** відкрий 2–3 посилання вручну. Нейромережа теж помиляється, особливо з цінами.

## 07 · АПКА · 5 промптів для міні-апок у чаті

У Claude такі програми з'являються поруч із чатом (Artifacts), у ChatGPT — у режимі Canvas. Пиши, що має робити програма, — а правки кажи словами.

1. `Зроби калькулятор вартості сайту: тип (лендинг / візитка / магазин), кількість сторінок, опції (форма, блог, оплата). Показуй підсумок і кнопку «скопіювати розрахунок».`
2. `Зроби трекер звичок на тиждень: додати звичку, відмітити день, прогрес у відсотках. Дані зберігай у браузері.`
3. `Зроби квіз з 5 питань для клієнтів [кав'ярні]: «яка кава вам підходить». Наприкінці — результат і кнопка «замовити».`
4. `Зроби таблицю задач з колонками «зробити / в роботі / готово» і перетягуванням карток.`
5. `Зроби генератор кольорової палітри: вводжу основний колір — отримую 5 відтінків з HEX і перевіркою контрасту.`

**Порада:** після першої версії пиши правки по одній: «кнопки більші», «додай темну тему».

## 09 · БЕНТО · Промпт: bento-секція

Bento — сітка з плиток різного розміру. Три правила: різні розміри плиток, один радіус кутів, одна думка на плитку.

```
Зроби bento-секцію переваг для [мого сайту].
5 плиток у сітці 3×3: одна велика (2×2) з головною перевагою, решта — по одній думці (цифра, відгук, гарантія, кнопка дії).
Один радіус кутів на всі плитки, однакові відступи, головна плитка — акцентним кольором.
На телефоні — плитки в одну колонку.
```

Якщо стоїть скіл ui-ux-pro-max — додай на початку: `Використай ui-ux-pro-max.`

## 10 · СКЛО · Glassmorphism: код і промпт

Скляна картка — три рядки CSS на кольоровому фоні:

```css
.glass {
  backdrop-filter: blur(16px);
  background: #ffffff1a;
  border: 1px solid #ffffff33;
  border-radius: 20px;
}
```

**Де пасує:** банкінг, музика, дашборди — короткий текст на яскравому фоні. **Де ні:** довгі тексти й дрібний шрифт — читати важко.

```
Зроби секцію з трьома скляними картками (glassmorphism) на градієнтному фоні: розмиття фону, напівпрозорий білий, тонка світла рамка. Перевір, щоб контраст тексту був не менше 4.5:1.
```

## 11 · БРУТ · Промпт: neo-brutalism лендинг

Брутал-стиль запам'ятовується саме тому, що виглядає «грубо»: товсті рамки, жорсткі тіні без розмиття, сирий шрифт, кислотні кольори. Пасує креативним агенціям, мерчу, подіям.

```
Зроби лендинг у стилі neo-brutalism для [бренду / події].
Товсті чорні рамки (3–4 px), жорсткі тіні зі зсувом без розмиття, 2–3 яскраві кольори, великий гротеск.
Кнопки — прямокутні, при наведенні тінь зникає (ефект «натискання»).
Секції: перший екран, 3 переваги, відгук, заклик до дії. Мобільна версія обов'язкова.
```

## 12 · ТІНЬ · Neumorphism: тіні і як не зламати читабельність

М'які «втиснуті» кнопки — це дві тіні на однаковому з фоном кольорі:

```css
.soft {
  background: #e6e7ee;
  border-radius: 16px;
  box-shadow: 8px 8px 16px #c5c6cc, -8px -8px 16px #ffffff;
}
.soft:active {
  box-shadow: inset 8px 8px 16px #c5c6cc, inset -8px -8px 16px #ffffff;
}
```

**Проблема:** кнопку погано видно — у неї майже немає контрасту з фоном. **Як виправити:** тонке обведення, колір лише на головній дії, темніший текст.

## 16 · СТИЛЬ · Шпаргалка: стилі сайтів і промпти

Скажи нейромережі стиль словом — і отримаєш зовсім інший дизайн. Додавай назву стилю на початок промпту.

- **Bento** — плитки різного розміру. `Зроби в стилі bento grid.`
- **Brutalism** — товсті рамки, жорсткі тіні. `Зроби в стилі neo-brutalism.`
- **Glassmorphism** — прозорі картки з розмиттям. `Зроби в стилі glassmorphism.`
- **Swiss** — сітка, великий гротеск, асиметрія. `Зроби у швейцарському стилі (Swiss design).`
- **Neumorphism** — м'які опуклі елементи. `Зроби в стилі neumorphism з нормальним контрастом.`
- **Minimal** — багато повітря, 1 акцентний колір. `Зроби мінімалістично: багато повітря, один акцент.`
- **Editorial** — як журнал, великі заголовки з засічками. `Зроби в редакційному (editorial) стилі.`
- **Dark tech** — темний фон, неонові акценти. `Зроби темну тему в стилі tech: неоновий акцент.`
- **Retro / Y2K** — яскраві градієнти, хром. `Зроби в стилі Y2K.`
- **Kinetic** — текст, що рухається. `Зроби заголовок з кінетичною типографікою.`

## 17 · ФОРМА · Шпаргалка: розміри полів і кнопок

Орієнтири, від яких форма виглядає охайно (звір з гайдлайнами Material / Apple HIG для свого проєкту):

- **Поле вводу:** висота 44–48 px, відступ тексту зліва 12–16 px, радіус як у кнопок.
- **Підпис (label):** 12–14 px, 6–8 px до поля, не зникає при введенні.
- **Помилка:** під полем, червоним, конкретно («Введіть e-mail»), не лише рамкою.
- **Кнопка:** висота як у поля, 44–48 px — зручно пальцем.
- **Між полями:** 16–24 px.

```
Приведи форму на сайті до однакових розмірів: поля і кнопки 48 px заввишки, відступ 16 px, label над полем 12 px, помилка під полем. Один радіус на все.
```

## 19 · ВІСІМ · Сітка 8 pt

Усі відступи кратні 8: 8, 16, 24, 32, 48, 64. Тоді не підбираєш «на око», а дизайн виглядає зібраним.

- Всередині елемента — менше (8–16), між блоками — більше (32–64).
- Одна шкала на весь сайт.
- Для дрібного (іконка й текст) можна 4.

```
Переглянь відступи на сайті й приведи їх до шкали 8 pt: 8, 16, 24, 32, 48, 64. Всередині карток — 16–24, між секціями — 64. Покажи, що змінив.
```

## 21 · РАДІУС · Шпаргалка: радіуси і настрій

Радіус кутів змінює характер сайту:

- **0–4 px** — строго: юристи, фінанси, B2B.
- **8–12 px** — дружньо: більшість сервісів і магазинів.
- **16–24 px** — м'яко: застосунки, дитячі й lifestyle-бренди.
- **999 px (пігулка)** — грайливо: кнопки, теги.

**Правило:** один радіус для системи (і, можливо, пігулки для тегів). Різні радіуси на одній сторінці виглядають випадково.

```
Зроби на всьому сайті один радіус кутів 12 px для карток, полів і кнопок; теги — пігулки. Перевір, щоб ніде не лишилось інших значень.
```

## 22 · МВП · Промпт MVP на 5 екранів і чекліст

Для першої версії застосунку вистачить п'яти екранів: онбординг, вхід, головна, одна головна дія, профіль. Усе інше — після перших користувачів.

```
Я роблю застосунок [для кого і навіщо].
Склади MVP на 5 екранів: онбординг, вхід, головна, головна дія, профіль.
Для кожного: що на екрані, які кнопки, куди веде.
Потім зроби робочий прототип цих 5 екранів. Дані поки тестові.
```

**Чекліст перед показом:** зрозуміло за 5 секунд, що це; головна дія — максимум 3 натискання; є порожні стани й помилки; працює на телефоні.

## 39 · ПАС · Формула PAS: промпт

PAS — проблема, загострення, рішення. Працює для оголошень, постів і перших екранів сайту.

- **Problem** — назви, що болить: «Сайт не приносить заявок».
- **Agitate** — загостри: «Щодня клієнти йдуть до конкурентів».
- **Solution** — рішення: «Сайт, що веде до заявки за 3 кліки».

```
Перепиши цей текст за формулою PAS: проблема → загострення → рішення.
3 варіанти: для поста в Instagram (до 60 слів), для оголошення (до 125 символів), для першого екрана сайту (заголовок + підзаголовок + кнопка).
Без вигаданих цифр і обіцянок. Текст: [встав свій]
```

## 41 · ПЛАН · Промпт: контент-план на місяць

```
Склади контент-план на 30 днів для Instagram.
Ніша: [що роблю]. Аудиторія: [хто вони, що їм болить]. Рубрики: [3–4 рубрики].
Таблиця: день, рубрика, тема, формат (рілс / карусель / сторіс), хук на перші 2 секунди, слово для коментарів.
Чергуй формати: 3 рілси і 2 каруселі на тиждень. Без повторів тем.
```

**Далі:** вибери найкращі 12–15, решту викинь, постав у календар і готуй по 3–4 за раз.

## 45 · КРЕО · Чекліст: 3 креативи на один оффер

Не роби одну рекламу — зроби три з різних кутів і залиш ту, що дає дешевші заявки.

1. **Біль** — що болить у клієнта зараз.
2. **Результат** — як буде після.
3. **Довіра** — відгук, кейс або ти в кадрі.

**Чекліст кожного креативу:**
- перші 2 секунди — хук, зрозумілий без звуку;
- один оффер і одна дія;
- субтитри;
- формат 9:16 і 4:5;
- без обіцянок, яких не можеш довести.

```
Мій оффер: [що продаю, кому, ціна]. Напиши 3 сценарії рекламного ролика по 15–20 с: кут «біль», кут «результат», кут «довіра». Для кожного: хук, 3 кадри, текст на екрані, заклик.
```
