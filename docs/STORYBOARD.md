# DevGuide — розкадрування (етап 07, режим «автономна вільна творчість» video-shotcraft)

Режим video-shotcraft: **автономна вільна творчість** (`references/pipeline.md`) — користувач доручив зробити все самостійно.
Шаблон Ink Press не використано: він під SaaS-дашборд, а DevGuide — навчальний сайт з одним меседжем.
Звідти взято правила (references/aesthetic-rules.md): R1 hold бренду ≥1 с, R2 прискорене «роздавання карт» + 0.5 с паузи,
R4 ≤3 повнокадрових удари, Q5 один герой у відкритті, Q11 мінімальна висота тексту, S2 таблиця SFX по кадрах, S4 фолі під дію.

## Продуктовий бриф (перевірено на сайті 2026-10-09)

- Що: DevGuide — навчання веброзробки українською, devguide.com.ua.
- Доказ: «Шлях навчання» з 8 напрямами (Claude/AI, Сайти, Google і аналітика, Instagram, Автоматизації, Відео й фото з AI, Дизайн/Figma, Telegram).
- Ментор: «Вадим Гук · технічний партнер», «Пиши код разом зі мною», «Я допоможу пройти шлях від ідеї до готового проєкту.»
- Пропозиція на сайті: «Перше заняття — 30 хвилин, безкоштовно» (дослівно, з датою перевірки в data/brand.json).
- Не використано: ціни, відгуки, статистика учнів, гарантії — їх немає в брифі.

## Дизайн-spec

- Палітра з brand.json: графіт `#080B0E`, текст `#F5F7F2`, лайм `#C3FF55` (+ допоміжні `#8EDFFF`, `#FF6B5E` лише для синтаксису/помилки).
- Шрифти локальні: Unbounded 700/900 (заголовки, кирилиця), Inter 400–800 (текст), JetBrains Mono 500 (код, кікери).
- Відступ від країв 84 px, робоча зона y 180–1650. Заголовки 76–104 px (гігантські 200–250 px — лише одне слово), текст 36–52 px, код 36 px.
- Скриншоти сайту — тільки всередині пристрою (світлий сайт на темній сцені = «реальний екран»), без перемальовування його UI.

## Альтернативи (по 30 с)

- **A — DevGuide-A-Kinetic**: тільки типографіка. Слова/літери GSAP, циклічний слот 8 напрямів з прискоренням, SVG-шлях, end card.
- **B — DevGuide-B-Depth**: два 3D-плани телефона (головна — crane, «Шлях навчання» — орбіта), 2.5D-нахилена сітка напрямів, end card.
- **C — DevGuide-C-Explainer**: Snapcn text-reveal → Snapcn terminal-simulator (`npm create vite@latest`) → Snapcn phone-frame зі скриншотом, сцена ментора, end card; титри через @remotion/captions + remotion-bits AnimatedText.
