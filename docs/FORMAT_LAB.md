## «Секретні коди»: корисності без голосу для Instagram (2026-10-11)

Формат «прогріву» на дні без зйомки: без голосу, музика на біт, 3–8 кодів у ролику. Каркас лаб. 15 (постер-інтро = обкладинка
на кадрі 0 → картки кодів → фінал «Напиши **КОДИ** в коментарях — пришлю набір секретних кодів у Direct»).
Джерело — дві інфографіки з чату («100 ChatGPT Secret Prompt Codes», «30 ChatGPT Secret Codes» для картинок).
Подача «секретні коди» — вибір Вадима; в кадрі кікер уточнює «фрази-промпти · працюють у будь-якому AI-чаті», бо прихованих функцій немає.

- Код: `src/tips/Tips.tsx` (10 луків), `src/tips/styles.tsx` (процедурні стилі картинок, SVG), рушій `src/system/beat.tsx` (спільний з лаб. 15–24).
- Контент: `data/tips.json` — коди, описи й повні промпти; слово CTA (`cta`) міняється там в одному місці.
- Збір: `node scripts/collect-tips.mjs` → `out/_корисності/` (MP4, обкладинки, `набір-кодів.md` для Direct, `опис-NN.txt` для посту).
