# Етап 5 — Snapcn і Remotion Bits


Прочитай AGENTS.md і data/brand.json, використовуй встановлені Remotion Skills та офіційні API-документи.
Відео українською, 1080×1920, 30 fps; окрема композиція, початкові демонстрації збережи.
Візуальний напрям: темний графіт, лаймовий акцент, сильна типографіка, редакційна композиція, чистий простір.
Зміст: навчання веброзробки через практику на власному проєкті з ментором. Без вигаданих гарантій, статистики та цін.
CTA: «Почни свій шлях із DevGuide» + devguide.com.ua.
Після реалізації: typecheck, короткий draft render, перевірка кадрів, виправлення, повний preview й final MP4.
Запиши технології, команди й виміряний час рендеру у docs/EXPERIMENT_RESULTS.md.

Зроби DevGuide-Components-Pro: 30 секунд демонстрації навчання й результату, переважно з готових компонентів.
1. Прочитай актуальний Snapcn skill і каталог https://snapcn.dev/. Обери 3–5 free компонентів: terminal, cursor/screen recording, title reveal, device frame, CTA/scene.
2. Налаштуй components.json та aliases за поточною документацією Snapcn/shadcn. Не запускай шадцн-команду в непідготовлений проєкт.
3. Встанови лише вибрані компоненти; не копіюй увесь каталог. За потреби використай npx shadcn@latest add @snapcn/text-reveal як перевірку.
4. Запусти npm run setup:extras -- bits. Прочитай API встановленої версії remotion-bits. Використай один text effect та один particle/motion primitive.
5. Усі компоненти оформлюй спільною темою DevGuide. Позбудься чужих демо-текстів і логотипів.
6. Не використовуй платні Pro-компоненти без наданого доступу. Якщо потрібна функція платна — реалізуй власний аналог.
7. Зроби фільм із єдиним ритмом, а не каталог ефектів. У звіті вкажи назви реально використаних компонентів і їхні джерела.
8. За наявності часу створи короткий окремий 8-секундний A/B-тест альтернативи RemotionUI або Onda із офіційного каталогу ресурсів; ліцензію й актуальне встановлення перевір у первинному репозиторії. Не змішуй всі бібліотеки у фінальну сцену.
