# Етап 0 — установка й перевірка

Працюй у поточному DevGuide Video Lab. Прочитай AGENTS.md, START_HERE_UA.md, docs/STACK.md, data/brand.json.
Я дозволяю встановити залежності цього проєкту і публічні скіли, виправити сумісність та зробити локальні рендери.

1. Перевір Node 22+, npm, Git. Виконай npm install, npm run check.
2. Виконай npm run setup:skills. Перевір реальні файли офіційних Remotion Skills, Snapcn та video-shotcraft. Прочитай відповідні SKILL.md. Якщо назва скіла відрізняється — використовуй фактичну.
3. Не оновлюй пакети навмання. Якщо оновлення необхідне, онови весь набір remotion/@remotion синхронно й перегенеруй lockfile.
4. Перевір поточні можливості через офіційну документацію, особливо useGsapTimeline. GSAP plugins через адаптер не підтримуються.
5. Спробуй прочитати https://devguide.com.ua і /learning. Збережи короткий фактологічний brief у docs/BRAND_RESEARCH.md. Якщо доступу немає, використовуй лише data/brand.json; не вигадуй програму чи ціни. Познач невідомі факти.
6. Склади план матеріалів. За наявності доступного браузера/інструмента зроби скриншоти відкритих сторінок; інакше використовуй локальні файли та графіку кодом.
7. Перевір список композицій: npx remotion compositions src/index.ts. Зрендери короткі уривки кожного технологічного стартера у 540x960. Відкрий кадри, перевір шрифти, GSAP, SVG/Lottie і 3D.
8. Напиши docs/EXPERIMENT_RESULTS.md: установлені версії, skills paths, що реально відрендерено, проблеми та виправлення.
9. Дай конкретні команди запуску й повідом, що готове для етапу 1. Не зупиняйся на плані, виконай перевірку.
