# Етап 6 — окремі Skia та Rive експерименти


Прочитай AGENTS.md і data/brand.json, використовуй встановлені Remotion Skills та офіційні API-документи.
Відео українською, 1080×1920, 30 fps; окрема композиція, початкові демонстрації збережи.
Візуальний напрям: темний графіт, лаймовий акцент, сильна типографіка, редакційна композиція, чистий простір.
Зміст: навчання веброзробки через практику на власному проєкті з ментором. Без вигаданих гарантій, статистики та цін.
CTA: «Почни свій шлях із DevGuide» + devguide.com.ua.
Після реалізації: typecheck, короткий draft render, перевірка кадрів, виправлення, повний preview й final MP4.
Запиши технології, команди й виміряний час рендеру у docs/EXPERIMENT_RESULTS.md.

Потрібні два незалежні 8–12-секундні тестові ролики. Не ламай базовий bundle.

A. DevGuide-Skia-Lab
- npm run setup:extras -- skia.
- Перевір актуальний peer dependency діапазон @shopify/react-native-skia; встанови сумісну версію і зафіксуй її.
- Виконай WASM/setup кроки й enableSkia за офіційною документацією, узгодь webpack із наявним enableTailwind.
- Створи графічне перетворення: шум → впорядковані контури → символ DevGuide. Один shader/blur або gradient ефект, а не купа ефектів.
- Рух і параметри shader driven by frame. Підвантаження WASM/assets завершується до render.
- Зроби actual headless render і перевір кадри. При несумісності створи окремий entrypoint для Skia, щоб інші композиції працювали.

B. DevGuide-Rive-Lab
- npm run setup:extras -- rive.
- Вивчи RemotionRiveCanvas API. Потрібен локальний public/assets/mascot.riv або інший ліцензований .riv.
- Якщо файла немає: перевір можливість отримати офіційний приклад із дозволеним використанням та зберегти його локально. Якщо це недоступно — явно познач BLOCKED_BY_RIV_ASSET; не створюй фальшивий .riv і не називай тест завершеним.
- Якщо файл є: використай коротку підтримувану timeline-анімацію, синхронізовану з Remotion. Не використовуй інтерактивний state machine без перевірки керованості кадром.
- Створи маленького помічника/символ, який підкреслює «Практика з ментором», без зайвого персонажного руху.

Завершення: два MP4 або один MP4 і точний опис блокера другого. Сумісність, розмір, час і фактичний візуальний результат запиши у матрицю.
