# Етап 1 — GSAP motion design


Прочитай AGENTS.md і data/brand.json, використовуй встановлені Remotion Skills та офіційні API-документи.
Відео українською, 1080×1920, 30 fps; окрема композиція, початкові демонстрації збережи.
Візуальний напрям: темний графіт, лаймовий акцент, сильна типографіка, редакційна композиція, чистий простір.
Зміст: навчання веброзробки через практику на власному проєкті з ментором. Без вигаданих гарантій, статистики та цін.
CTA: «Почни свій шлях із DevGuide» + devguide.com.ua.
Після реалізації: typecheck, короткий draft render, перевірка кадрів, виправлення, повний preview й final MP4.
Запиши технології, команди й виміряний час рендеру у docs/EXPERIMENT_RESULTS.md.

Створи DevGuide-GSAP-Pro: 30-секундний motion design ролик з 6 сцен.
0–3: «Дивишся уроки. А що створюєш?» — сильний типографічний hook.
3–7: розрізнені блоки коду стають логічною структурою.
7–12: HTML → CSS → JavaScript → React; слова рухаються і перетворюються на UI.
12–18: курсор, написання коду, видимий результат; власний спрощений демонстраційний інтерфейс.
18–25: менторство й практика, один головний меседж на кадр.
25–30: бренд і стабільний CTA без зайвого руху.

Використай useGsapTimeline для DOM/SVG, stagger, nested timelines, easings, контрольовані overlaps.
Текст поділи JSX на слова/літери. Не використовуй SplitText, ScrollTrigger чи інші GSAP plugins.
Додай 2–3 match cuts: збереження форми/позиції елемента між сценами. Середні сцени різні за ритмом.
Початок має читатися з першого погляду; не рухай одночасно всі елементи. Один помітний акцент за раз.
Музика й короткі SFX підтримують дію. Перший draft може використати lab-bed.wav; для фінального запропонуй/використай наданий трек.
Зроби сцени окремими компонентами, дизайн-токени та таймінги винеси в дані. Додай npm-команду render:gsap-pro.
