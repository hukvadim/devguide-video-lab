# DevGuide Video Lab

Почни з **START_HERE_UA.md**.

```bash
npm install
npm run check
npm start
```

Після цього: `npm run setup:skills` і промпт `prompts/MASTER_PROMPT.md` у Claude Code / Codex.

Готові стартери: GSAP, Three.js, SVG/Lottie, титри та hybrid.
`examples/` містить перевірене 30-секундне прев'ю стартової збірки, якщо воно включене у цей архів.
Це основа для експериментів. Авторський фінальний ролик створюється агентом за наданими промптами.
