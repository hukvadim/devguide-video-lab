# DevGuide Video Lab — почни тут

Готовий переносний Remotion-проєкт + п'ять стартових композицій + поетапні промпти для Claude Code / Codex.
Мета: порівняти технології на однаковому бренді, а потім створити сильний авторський ролик DevGuide.

**Стартові композиції — технологічні демонстрації. Фінальний рекламний ролик агент створює за промптами.**
`npm install` встановлює бібліотеки; AI-скіли встановлюються окремо. Для прев'ю та рендеру стартових композицій AI і API-ключі не потрібні.

## 0. Продовжити роботу на іншому ПК (GitHub)

Проєкт лежить у приватному репо `hukvadim/devguide-video-lab`. Скіл монтажу `devguide-reel` уже всередині
(`.claude/skills/devguide-reel/`), тож Claude Code бачить його, щойно відкриєш папку.

```bash
git clone git@github.com:hukvadim/devguide-video-lab.git
cd devguide-video-lab
npm install
npm run setup:skills
node .claude/skills/devguide-reel/scripts/setup.mjs
```

- `setup.mjs` ставить ffmpeg, whisper, моделі (~600 МБ) і звуки. Якщо поруч є `~/.claude/skills/edit-video`, бере його моделі.
- Сирі записи (`5/` та інші папки днів), `out/` і `.env` у git не потрапляють. Переноси їх диском або хмарою, ключі вписуй у `.env` заново.
- Контент-план: `docs/CONTENT_STRATEGY.md`, `docs/CONTENT_BACKLOG.md`, озвучка: `docs/ELEVENLABS.md`.
- Змінив скіл або документи → `git add -A && git commit && git push`, на іншому ПК `git pull`.

## 1. Підготуй інший комп'ютер

- Встанови Node.js 22 LTS або 24 LTS та Git. Git потрібен для завантаження скілів.
- Розпакуй ZIP у звичайну папку, наприклад `D:\Projects\devguide-video-lab`.
- Відкрий саме цю папку у VS Code. У терміналі має бути видимий `package.json`.
- Для промптів потрібен Claude Code / Codex зі своєю авторизацією. Оплата агента не входить у Remotion.

```bash
node --version
git --version
npm install
npm run check
npm start
```

У Remotion Studio вибери композицію. Усі початкові композиції: 1080×1920, 30 fps, 30 секунд.
Інтернет потрібен під час установки та першого завантаження браузера рендерера.
Шрифти, Lottie та оригінальний простий звуковий фон уже локальні.

## 2. Встанови скіли для агента

```bash
npm run setup:skills
```

Команда встановлює офіційні Remotion Skills, Snapcn skill і video-shotcraft у контекст проєкту для Claude Code / Codex.
Якщо агент уже був відкритий — перезапусти сесію, щоб він побачив скіли.
Перевір появу каталогів `.agents/skills`, `.claude/skills` або каталогу, який повідомив skills CLI.
Назви та структура можуть відрізнятися між версіями CLI. Агент має підтвердити, які SKILL.md він реально прочитав.

Ці скіли не вбудовані у ZIP: завантажуються з оригінальних репозиторіїв. Snapcn skill не встановлює всі Snapcn-компоненти; потрібні компоненти додає агент.

## 3. Дай агенту перший промпт

Відкрий `prompts/00_SETUP_AND_AUDIT.md`, скопіюй його цілком у Claude Code / Codex.
Він перевірить проєкт, джерела бренду, скіли та базовий рендер.

Далі тестуй **по одному**:

| Етап | Файл промпту | Що порівнюємо |
|---|---|---|
| 1 | `01_GSAP_MOTION.md` | Монтаж, типографіка, GSAP |
| 2 | `02_THREE_3D.md` | Three.js, камера, світло, 3D |
| 3 | `03_VECTOR_LOTTIE.md` | SVG, промальовування, Lottie |
| 4 | `04_CAPTIONS_AUDIO.md` | Титри, голос, ритм, звуковий дизайн |
| 5 | `05_COMPONENT_LIBRARIES.md` | Snapcn та Remotion Bits |
| 6 | `06_SKIA_RIVE_EXPERIMENTS.md` | Два окремі додаткові експерименти |
| 7 | `07_SHOTCRAFT_HERO.md` | Сценарій і режисура video-shotcraft |
| 8 | `08_FINAL_HYBRID_QA.md` | Фінальний ролик із найкращих прийомів |

Не хочеш проходити всі етапи? Після встановлення дай `prompts/MASTER_PROMPT.md`.
Він доручає агенту пройти установку, створити три альтернативи, перевірити їх і зібрати фінальний ролик.

## 4. Збережи стартові ролики

```bash
npm run render:preview
npm run render:gsap
npm run render:3d
npm run render:svg
npm run render:captions
npm run render:hybrid
```

`render:preview` робить 540×960 для швидкого перегляду. Інші команди — 1080×1920 H.264, CRF 18.
Для 3D на системі без GPU спробуй `npm run render:3d -- --software`.
Кожне відео отримує свою папку `out/<назва>/` (наприклад `out/hybrid/`), галерея всіх рендерів: `out/index.html` (`npm run out:index`). Для всіх п'яти початкових композицій: `npm run render:all`.

```bash
npm run qa:frames -- Hybrid
```

Це експортує шість контрольних кадрів у `out/<назва>/qa/`. Після AI-змін можуть з'явитися нові ID композицій:
агент повинен додати відповідні npm-команди або дати точну команду `npx remotion render`.

## 5. Додаткові бібліотеки

Вони встановлюються окремо, щоб експериментальна залежність не ламала базовий проєкт:

```bash
npm run setup:extras -- bits
npm run setup:extras -- rive
npm run setup:extras -- skia
```

Remotion Bits встановлюється за актуальною версією з npm і фіксується у package.json.
Для Skia потрібна додаткова конфігурація WASM / webpack з офіційної документації. Просто install недостатньо.
Для Rive потрібен придатний локальний `.riv`-файл. Його у ZIP немає; промпт описує порядок додавання.
Окремі експерименти агент додає так, щоб базові композиції залишалися працездатними.

## 6. Що змінити під себе

- `data/brand.json` — назва, посилання, повідомлення, палітра.
- `public/assets/` — поклади справжні скриншоти, фото Вадима, логотип, голос.
- `docs/ASSET_CHECKLIST.md` — перелік потрібних матеріалів.
- `docs/STACK.md` — стек і призначення залежностей.
- `docs/TEST_MATRIX.md` — порівняння технологій та критерії оцінки.
- `docs/TROUBLESHOOTING.md` — типові проблеми.
- `VALIDATION.md` — що реально перевірено під час складання цього ZIP.

Ціни, відгуки, статистика учнів і обіцянки працевлаштування не внесені. Перед використанням таких тверджень дай агенту підтверджені актуальні дані.
