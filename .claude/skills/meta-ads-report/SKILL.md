## Жорсткі межі
- **Тільки читання.** Не змінювати бюджети, кампанії, набори, аудиторії, оголошення. Будь-яка зміна — пропозиція, рішення і дія за Вадимом.
- Якщо в MCP `meta-ads` з'явились write-інструменти (create/update/pause/delete/budget) — не викликати, сказати Вадиму і запропонувати `permissions.deny`.

- Не вигадувати цифр. Кожна цифра — з MCP або дашборда.

## Процес
1. **Meta (MCP).** `ads_get_ad_entities`, `level=ad`, період з запиту (типово `yesterday` + `maximum` для накопиченого). Поля: `name, adset_name, effective_status, delivery, amount_spent, impressions, reach, frequency, ctr, cpc, cpm, results, cost_per_result`. Плюс `ads_get_errors` для кампанії. Перевіряй поля через `ads_get_field_context`, якщо додаєш нові. Виконай `next_actions` з `read_only: true`.
2. **Ліди.** `ArtifactData` list `leads` → по країні й оголошенню: написали, записались (`booked`+), консультація відбулась (`held`+), оплатили, відмови з причинами. Без `isTest`.
3. **Порахуй:** ціна розмови; **ціна проведеної консультації** (головна) = витрати ÷ held; ціна оплати; день тесту; накопичено vs стеля 20 000 ₴.
4. **Перевір правила:**
   - оголошення > 599 ₴ і 0 розмов → чи вимкнуло його правило «Стоп»;
   - ~5 880 ₴ за 7 днів без проведених консультацій і перспективних записів → рекомендувати паузу для діагностики;
   - частота > 3 за 7 днів → вигорання креативу;
   - дні 1–4 → нічого не міняти;
   - день 14 → правило Вадима: продовжувати країну з прийнятною ціною проведеної консультації і перспективою оплат, інакше пауза.
5. **Для глибшого розбору (день 7+)** — скіли aaron-marketing: `fatigue-frequency-manager`, `budget-pacing-monitor`, `ad-account-auditor`.
6. **Trello:** коментар з цифрами в картці ритуалу дня / «Аналіз PL vs DE»; проблема → картка в «🐞 Баги»; виконане → «✅ Зроблено».

## Формат відповіді (коротко, українською)
1. Одне речення: як справи і чи треба щось робити.
2. Таблиця PL | DE: витрати, покази, CTR, CPC, CPM, розмови, ціна розмови, записи, консультації, ціна консультації, оплати.
3. Оголошення: що крутиться, що ні, статуси.
4. Правила: які спрацювали.
5. Рекомендація: максимум 1–2 дії з позначкою «рішення Вадима»; якщо дні 1–4 — «нічого не міняти».
Висновки про переможця — лише з урахуванням того, що «5 консультацій і різниця 30%» — практичний сигнал, не доказ.
