# Як працювати в цьому репо (для Claude Code)

Користувач каже, яке відео треба, а ти: питаєш формат (F1–F7 з `docs/CONTENT_STRATEGY.md`) і слово-CTA, якщо їх немає, пишеш сценарій, кодиш ролик, рендериш і показуєш.
- Скіли: `devguide-ideas` (ідея → картка → сценарій → ролик), `devguide-reel` (монтаж сирого відео), Remotion-скіли (`npm run setup:skills`).
- Перегляд: `npm start` (Remotion Studio, localhost:3000) або `out/index.html`. Рендер: `node scripts/render-timed.mjs draft <CompositionId>` (прев'ю), потім `final`.
- UGC-вставки з Вадимом: `docs/UGC_FLOW.md` (промпти для Flow), клипи в `public/assets/ugc/flow/`, компонент `src/system/ugc.tsx`.
- `.env` (ключ ElevenLabs) у git не їде; без нього озвучку не генеруємо, працюємо з текстом, музикою й SFX.

## Уподобання автора (перенесено з пам'яті Claude, діють на всіх ПК)
- **Заборонений звук:** `switch-click-quick.mp3` (Mixkit 2582) ніколи. SFX лише на реальні події сцени (поява сцени, картка, склейка), кілька на хвилину. Не став SFX на кожну фразу/слово чи рівну сітку, не повторюй один короткий звук багато разів.
- **Заборонена палітра:** коралове/червоне на синьому (`#F45267` на `#0166BD`, Color Drop #14), нечитабельне. Акцентний текст ≥3:1 контрасту з фоном; насичені кольори лише для заливок.
- **Кінетичний «одне слово на біт»** (`look="word"` у `src/system/step.tsx`) не для озвучених пояснень: скаче й не читається. Для озвучки `scenes` або `look="karaoke"`; слова по одному лише для слоганів на 3–6 слів.
- **Улюблений формат без голосу:** музика на біт, перші ~3 с постер-титул, далі пронумеровані картки (lab 15 «5 промптів»). Кадр 0 уже має бути готовим постером (обкладинка Instagram, без чорних плиток), заголовок у центральній зоні 3:4, `cover.jpg` на відео.
- **Без голосу потрібні візуали:** кожна картка = одна картинка (UI-макет, схема, палітра, до/після) + ≤6 слів. Картки з текстом промптів провалилися. Перед пакетним рендером покажи обкладинку й 2 кадри на погодження.
- **Канали:** DevGuide = відео до кроків навчального шляху (F1, CTA на наступний крок); Instagram (особистий і DevGuide) = ріст через «напиши СЛОВО в коментарях → бот шле в Direct». З кожного запису бажано робити ще й рілс.
- Скіл `devguide-reel` живе в цьому репо (`.claude/skills/devguide-reel/`), зміни коміть і пуш.
