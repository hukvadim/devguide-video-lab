# Перебивки DevGuide · 150 кліпів

Поклади цей файл у `devguide-video-lab/public/assets/ugc/flow/`. Початковий стан за скриншотом — **18 наявних, 132 у черзі**. Наявні кліпи лишаються зі своїми назвами. ID в каталозі постійні, навіть якщо зміниш порядок генерації.

## Як користуватись

1. Перші п’ять для тесту — **019** тихе вау, **030** руки на клавіатурі, **064** стрілка між блоками, **096** дорога в Поздимирі, **140** ідея з блокнота. Вони перевіряють п’ять різних типів кадру.
2. У Flow вибери Video, вертикаль 9:16, один результат і 4–6 секунд, якщо обрана модель підтримує таку тривалість. Для кадрів з обличчям додай той самий референс персонажа, якщо модель і режим дозволяють. Для кадрів рук або предметів референс обличчя можна пропустити.
3. Встав англійський опис сцени й додай базовий суфікс нижче. Для монтажу зазвичай достатньо найвиразніших 1–3 секунд.
4. Збережи відібраний кліп як `br-019.mp4` (підстав потрібний ID), тоді заміни `[ ]` на `[x]`. Якщо кліп потребує перегенерації, лиши чекбокс порожнім і допиши причину біля рядка.
5. Для двох ПК тримай один спільний каталог статусів. На старті достатньо синхронізувати цей файл та окремо мати доступ до MP4. Перед початком сесії відкрий актуальну версію і познач вибрані ID як `у роботі`, якщо обидва ПК використовуються паралельно.

Базовий суфікс для Flow

> Vertical 9:16 smartphone B-roll. One continuous shot, one clear action. Keep the important action in the central area. No dialogue, captions, logos or readable interface text.

Для кліпів з референсом

> Match the person’s face, hair and beard to the supplied reference. Keep his appearance consistent throughout the shot.

Для справжнього туторіалу з Blender, Godot, Flow або коду використовуй запис власного екрана, коли глядачу треба повторити крок або прочитати інтерфейс. Ідеї з умовними екранами в каталозі призначені для ілюстрації під озвучку.
