# Flow B-roll

Розширення Chrome і локальний сервер. Разом вони по черзі генерують перебивки з `public/assets/ugc/flow/FLOW_BROLL.md` у Google Flow.
Готовий кліп зберігається як `flow/br-NNN.mp4`, у `FLOW_BROLL.md` ставиться `[x]`, а в `ugc.json` дописується рядок (from 0.5, dur 2.5; правиться руками).

Запуск:
1. Сервер: двічі клікни `start-hidden.vbs`. Можна покласти ярлик на нього в `shell:startup`, тоді він стартуватиме з Windows.
2. Відкрий у Flow проєкт, де лежать `avatar2-2000.jpg` і `36d6f794-….png`. Панель з'явиться зліва знизу.
3. «Наступні 10» (або «Тест 5») → ▶ Старт. Вкладку Flow не згортай: Chrome показує смугу «налагоджується», так і має бути.

Що варто знати:
- Якщо відео згенерувалось, а збереження впало, повторний ▶ Старт лише докачає його, нових кредитів не витратить.
- Статус кліпу = чи є файл на диску.
- У Flow має бути ввімкнено «Повернути відео без звуку» (шестерня вгорі справа).

Встановлення розширення (один раз): `chrome://extensions` → Режим розробника → «Завантажити розпаковане» → ця папка.
Перевірка логіки: `node tools/flow-broll/lib.test.js`. Селектори Flow лежать у `content.js`.
